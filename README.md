# F1 2026 App — Результаты Гран-при и календарь Формулы-1

Кроссплатформенное мобильное приложение на фреймворке **Flutter** для отслеживания календаря, дат, автодромов и результатов этапов чемпионата мира Формулы-1 сезона 2026 года.

## Реализованные лабораторные работы:

- **Лабораторная работа №1:** Создание проекта, настройка сред сборки Flutter/Dart, базовая структура приложения.
- **Лабораторная работа №2:** Верстка главного экрана (часть 1) — тема приложения (темная гоночная палитра F1), маршрутизация с `go_router`, карточки элементов `GpCard` с ассетами и бейджами раундов, логирование через `talker`.
- **Лабораторная работа №3:** Верстка экрана деталей (часть 2) — детальный просмотр выбранного этапа, характеристики автодрома (`CircuitInfoWidget`), результаты гонки и подиум (`PodiumWidget`), обзор уикенда.
- **Лабораторная работа №4:** Архитектура BLoC и HTTP-клиент Dio (часть 1) — настройка `Dio` с логированием `TalkerDioLogger`, модель `GrandPrix` с JSON-сериализацией, `F1Repository`, BLoC главного экрана (`HomeBloc`) с обработкой состояний загрузки, успеха и ошибок.
- **Лабораторная работа №5:** Архитектура BLoC и HTTP-клиент Dio (часть 2) — BLoC экрана детальной информации (`DetailsBloc`), получение отдельного элемента по ID через REST API, сервис-локатор `get_it`, обработка ошибок с возможностью повтора запроса.

---

## Архитектура и стек технологий:
- **UI Framework:** Flutter (Material 3)
- **Управление состоянием:** `flutter_bloc`, `bloc`, `equatable`
- **Сетевой стек:** `dio`, `talker_dio_logger`
- **Маршрутизация:** `go_router`, `talker_route_observer`
- **Внедрение зависимостей:** `get_it`
- **Логирование:** `talker`, `talker_flutter`, `talker_bloc_logger`
